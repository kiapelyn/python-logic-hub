# Python Logic Hub & Data Structures

Repositório destinado ao versionamento de exercícios práticos, algoritmos e estruturas de dados desenvolvidos ao longo da graduação.

## Visão Geral

O objetivo deste repositório é organizar e documentar a evolução no aprendizado da linguagem Python, cobrindo desde os fundamentos de lógica de programação até estruturas de dados dinâmicas e algoritmos de grafos.

## Conteúdo Programático

### Semestre 1 — Lógica e Fundamentos
* Operações aritméticas e expressões lógicas
* Estruturas condicionais (if, elif, else) e fluxo com match/case
* Laços de repetição (for, while)
* Manipulação inicial de listas e arrays
* Modularização com funções

### Semestre 2 — Algoritmos Avançados e Arquivos
* Funções e recursividade
* Manipulação avançada de strings
* Matrizes e vetores multidimensionais
* Mapeamentos com dicionários e uso de tuplas
* Leitura e manipulação de arquivos de texto (.txt, .csv)
* Algoritmos de busca (Linear e Binária) e ordenação (Bubble, Insertion, Selection, Quick, Merge)
* Tipos Abstratos de Dados (TAD)

### Semestre 3 — Programação Orientada a Objetos e Estruturas de Dados
* Paradigma de Programação Orientada a Objetos (Classes, Objetos e Métodos)
* Estruturas de Dados Lineares Dinâmicas:
  * Listas Encadeadas / Ligadas (LinkedList)
  * Pilhas (Stacks)
  * Filas (Queues)
* Estruturas Não-Lineares:
  * Árvores Binárias e Árvores de Busca
  * Grafos, Matrizes/Listas de Adjacência e Algoritmos de Percurso

## Execução dos Códigos

### Pré-requisitos
* Python 3.10 ou superior instalado.

### Passos para execução

1. Clone o repositório:
   git clone https://github.com/seu-usuario/python-logic-hub.git

2. Acesse o diretório do projeto:
   cd python-logic-hub

3. Execute o script desejado informando o caminho correspondente:
   python semestre_1/01_operacoes_basicas/nome_do_script.py
